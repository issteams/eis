# Security Policy

## Supported versions

Security fixes are applied to the current maintained release line.

## Reporting a vulnerability

Please do not disclose suspected security vulnerabilities in a public issue.

Report a vulnerability privately through the security contact configured for
the repository or through GitHub's private vulnerability reporting feature when
available.

Include:

- a clear description of the vulnerability;
- affected component or path;
- reproduction steps or a minimal proof of concept;
- the potential security impact;
- any relevant logs or test cases that do not contain secrets.

Do not include API keys, passwords, access tokens, private keys, personal data,
or other confidential information in a report.

## Disclosure

Please allow the maintainers reasonable time to investigate and prepare a fix
before publicly disclosing a vulnerability.
