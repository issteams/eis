## Detailed architecture

The `docs/architecture/` directory contains focused documents for the core runtime, context retrieval, organizational intelligence, model abstraction, agents, tools, verification, integrity, integrations, autonomous workflows, performance, production operations, specialized agents, and security/governance.

## Documentation rule

Documentation must describe actual behavior. Planned capabilities must be identified as future work, and examples must use public APIs or repository files that exist at the documented revision.
